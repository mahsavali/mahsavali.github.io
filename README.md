# Mahsa Vali — Academic Website

Personal academic website for GitHub Pages, based on the Editorial template by HTML5 UP.

## Deploy
Upload the **contents of this folder** to the root of the `mahsavali.github.io` repository. `index.html` must remain in the repository root.

The site includes light/dark mode, a purple theme, CV, profile photo, and links to Google Scholar, LinkedIn, ResearchGate, GitHub, and ORCID.
